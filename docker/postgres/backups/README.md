# Local Postgres Backups

Put logical backups here before first `docker compose up`.

- `sdss.sql` or `sdss.dump` restores into database `sdss`
- `simba_circactivity.sql` or `simba_circactivity.dump` restores into database `simba_circactivity`
- `simba_sdss.dump` restores into database `simba_sdss`

`benchmark_mdi` is generated by `docker/postgres/init/10-benchmark_mdi.sql`,
so it does not need a backup file.

Backups are ignored by git. Reset the Docker volume to rerun restores:

```bash
docker compose down -v
docker compose up -d
```
